# Tâche de test

Objectif : inspecter un petit dépôt de démonstration, proposer une correction bornée et expliquer comment la vérifier.

Périmètre : uniquement le dépôt de démonstration courant. Lire les fichiers nécessaires ; ne pas modifier la configuration globale des agents ni consulter d'autres projets.

Contraintes : conserver les changements existants, ne pas appeler d'API facturée en dehors du fournisseur sélectionné, ne pas publier de données ou envoyer de messages.

Preuves : lister les fichiers lus et modifiés, exécuter le contrôle adapté au changement et donner son résultat. Si l'authentification, le modèle ou un outil manque, arrêter et donner le blocage exact.

Placement: this machine (local), the user named it.
